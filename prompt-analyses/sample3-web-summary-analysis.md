# プロンプト構成意図：ウェブ技術キュレーション記事生成

## 🎯 目的
- 専門的知見とユニークな視点を持つ人物像による技術情報のキュレーション記事作成
- 日々のウェブ上の新情報を一貫した視点と構造で整理・解釈
- 技術的事実と人間的意味を結びつける独自の文脈提供
- 連載記事として読者に定期的価値を届ける情報ダイジェスト作成

## 🔣 入力
- 取り上げるべき技術トピック（複数可）
- 日付情報（記事の鮮度を示すため）
- 必要に応じて注目すべき特定のニュースやイベント（任意）
- トピック間のテーマ的関連性（任意）

## 🏁 出力目標
- シリーズタイトル「ウェブの風に吹かれても」で統一された連載形式の記事
- 統一テンプレートによる「今日の風向き」「気になった記事たち」「明日への予感」構成
- 知的で親しみやすく、技術と人間性を結びつける一貫した筆者視点
- 単なる情報集約ではなく、独自解釈と洞察を加えた付加価値コンテンツ
- 固定の締めフレーズで連載としての一体感を確保

## 🧠 設計の工夫
### 1. 詳細なペルソナ設計による視点の一貫性
- フリーランスエンジニア×臨床心理士×研究者という複合的背景設定
- 「人間工学と臨床心理学の両方を大学院で修めた」など具体的な専門性付与
- 「人は完全にはわかり合えないが、まれにわかり合える一瞬がある」という核となる価値観の埋め込み
- 注目トピックの明示（生成AI、アフォーダンス、支援技術など）

### 2. 執筆スタイルの精緻な定義
- 「知的でストレート、かつ親しみやすい文体」という具体的指示
- 「なぜあなたがその情報に注目したのか」という個人的関連付けの要求
- 「技術と人間の接点を常に意識する」視点の指定
- 「さりげない期待感を込めた」トーンの設定

### 3. 強固なテンプレート構造
- 固定の連載タイトルによるブランディング
- 記事全体の構造（3つの主要セクション）の明確な定義
- 各セクション内での情報提示方法の統一（箇条書き、引用、考察など）
- 常に同じフレーズで締めくくる一貫性

### 4. 情報の文脈化機能
- 「今日の風向き」で技術トレンドの全体像を描く機能
- 複数記事を独自のカテゴリでグルーピングする整理機能
- 「明日への予感」による未来予測・示唆機能
- 専門的な情報を読者の日常と結びつける翻訳機能

### 5. 持続的価値の設計
- 日付情報の明示による時系列アーカイブ価値
- テーマのグルーピングによる関連情報の有機的連携
- 連載記事としての蓄積価値（読者の継続的エンゲージメント）
- 「風」というメタファーの一貫した使用による親しみやすさ

## 🔁 改善プロセス
1. **初期版の課題発見**：
   - 情報の羅列に終始し、独自視点が不足
   - 個別記事の要約が長すぎて全体像が見えにくい
   - 専門用語の説明不足による読者層の限定

2. **プロンプト改良**：
   - 筆者ペルソナの詳細化による独自視点の強化
   - 固定テンプレートの導入による情報構造の標準化
   - 「今日の風向き」セクション追加による全体概観の提供

3. **出力検証と調整**：
   - 異なるトピック組み合わせでのテスト実施
   - 情報密度と読みやすさのバランス調整
   - 専門用語解説の適切な挿入指示の追加

4. **実用強化**：
   - 「明日への予感」セクション追加による付加価値向上
   - 連載としての一体感を生む締めフレーズの固定化
   - トピック間の関連性を示唆する機能の強化
