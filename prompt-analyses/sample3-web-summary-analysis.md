# Webサイト技術まとめ記事プロンプトの設計意図およびプロンプト構成例

## 設計意図

このプロンプトは、特定の人物像を演じながらウェブ上の情報をまとめる日次記事を生成するためのものです。主な設計意図は以下の通りです：

1. **人格付け（ペルソナ設定）** - 特定のバックグラウンド、専門知識、価値観を持つ人物として情報をまとめることで、一貫した視点と独自の解釈を提供
2. **執筆スタイルの統一** - 知的でありながら親しみやすく、技術と人間性を結びつける視点を常に持ち、個人的関心を示す
3. **構造化された出力** - 「ウェブの風に吹かれても」というシリーズタイトルと固定テンプレートを使用して一貫性のある記事を作成
4. **情報キュレーション** - ウェブ上の情報から価値あるものを選び、独自の視点で解釈し、未来への示唆を与える

## プロンプト構成の分析

このプロンプトは以下の要素から構成されています：

### 1. プロフィール設定
- 職業的背景（フリーランスエンジニア、臨床心理士など）
- 学術的背景（人間工学と臨床心理学）
- 研究・関心領域（生成AI、アフォーダンス、ナラティブアプローチなど）
- 核となる価値観（「人は完全にはわかり合えないが...」）

### 2. 執筆スタイル指定
- 文体（知的・ストレート・親しみやすい）
- 視点（技術と人間の接点）
- 個人的関連付け（自分がなぜ注目したか）
- 本質重視（流行追従ではなく）
- トーン（さりげない期待感）

### 3. 構造的制約
- シリーズタイトル
- テンプレート使用の義務付け
- 締めの固定フレーズ

### 4. 具体的テンプレート
詳細な記事構造が提供されており：
- タイトル形式
- 冒頭部分
- 「今日の風向き」セクション
- 「気になった記事たち」セクション（複数のテーマグループに分類）
- 「明日への予感」セクション
- 締めのフレーズ

## プロンプト活用例

このプロンプトは以下のように活用できます：

```
[生成指示（前提設定）の部分をそのまま使用]

以下のトピックについて、今日のウェブ記事をまとめてください：
1. 大規模言語モデルにおける最新の進展
2. リモートワークの新たなツールとその心理的影響
3. AIと芸術の融合に関する最近の事例

今日の日付：2023年10月15日
```

## 強みと応用可能性

- **一貫した視点**: 特定のペルソナを通して情報を提示することで、単なる要約以上の価値を提供
- **構造化された情報整理**: 読者が定期的に同じ形式で情報を受け取ることで理解が促進される
- **技術と人間性の橋渡し**: 純粋な技術情報だけでなく、その人間的意味や未来への影響を考察
- **応用**: ニュースレター、ブログ連載、情報キュレーションサービスなど様々な形式で応用可能

このプロンプト設計は、AIに特定の視点と構造をもたせることで、単なる情報集約ではなく、意味のある解釈と洞察を提供するように工夫されています。
