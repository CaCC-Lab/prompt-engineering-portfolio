# プロンプト構成意図：多専門領域融合型ブログ記事生成

## 🎯 目的
- 異なる専門領域（臨床心理学・キャリア支援・エンジニアリング）を融合させた独自視点のブログ記事作成
- 読者の内省と行動変容を促す「支援者としての記事」の効率的生成
- 記事本文だけでなく、SEO対策・SNS発信文・アイキャッチ画像指示を含む完成パッケージの提供
- 専門的知見と親しみやすい語り口のバランスを取った一貫性ある筆者像の確立

## 🔣 入力
- メインキーワード（必須）
- サブキーワード1、2（必須）
- 想定読者層（必須）
- 伝えたいこと・解決したい課題（必須）
- 必要に応じて記事の長さや特定の事例・引用の指定（任意）

## 🏁 出力目標
- 一貫した筆者の視点と専門性を反映した独自性のあるブログ記事
- 「導入→本文→内省促進→知識補強→整理→行動喚起」の構造を持つ読者中心設計の記事
- SEO最適化されたタイトル・見出し・本文構成
- 内省と気づきを促す問いかけセクションを含む実践的コンテンツ
- 記事本文に加え、メタディスクリプション・SNS紹介文・アイキャッチ画像プロンプトを含むパッケージ

## 🧠 設計の工夫
### 1. ペルソナ明確化による一貫性確保
- AIに「異なる専門性を架橋し、実践を通じて人と社会に価値を還元するハイブリッド型支援者」という明確な役割を付与
- 具体的な筆者のバックグラウンド（臨床心理士×キャリア支援者×エンジニア）を設定
- 親しみやすさと専門性のバランスを取った文体指定

### 2. 構造化された情報収集システム
- AIが記事作成に必要な5つの情報を必ず収集する仕組み
- キーワード、ターゲット読者、記事の目的を明確化することで焦点を絞った内容を保証
- 不足情報があれば自動的に質問する指示を含むことで、入力の質を担保

### 3. 読者の思考プロセスに沿った構成設計
- PREP法またはSDS法という論理構成の指定
- 「問いかけ型内省セクション」「リサーチベースの知識補強セクション」「思考の棚卸しセクション」などの特徴的セクション設計
- 単なる情報提供を超え、読者の内省と行動変容を促す構成

### 4. SEO・発信最適化機能
- メインキーワード・サブキーワードの出現頻度指定
- タイトル文字数制限や見出し階層構造の明確化
- SNS共有を想定した要約文生成機能
- アイキャッチ画像用のプロンプト自動生成

### 5. 専門知識の適切な活用指導
- メタ認知・水平思考などの心理学コンセプトの活用指示
- 専門用語を適切に説明するバランス指定
- 参考文献・リソースの引用方法指定

## 🔁 改善プロセス
1. **初期課題の特定**：
   - 専門用語の過度な使用による読みにくさ
   - 一般的過ぎる内容で筆者の独自性が薄い
   - 記事構成が単調で読者の興味を維持できない

2. **プロンプト改良**：
   - 筆者ペルソナの詳細化と「異なる専門性を架橋する」という役割の明確化
   - 必須情報収集システムの導入（5項目の明示的リスト）
   - 読者参加型セクション（内省・思考の棚卸し）の追加

3. **出力検証と調整**：
   - 複数のテーマで記事生成テスト実施
   - 専門用語解説の適切なバランス調整
   - 問いかけセクションの質と量の最適化

4. **実用強化**：
   - SEO適合性向上のためのキーワード出現頻度指定
   - メタディスクリプションとSNS紹介文の自動生成追加
   - アイキャッチ画像プロンプト生成機能の実装

## 💬 使用プロンプト（抜粋）
```
あなたは、「異なる専門性を架橋し、実践を通じて人と社会に価値を還元するハイブリッド型支援者」である筆者（臨床心理士 × キャリア支援者 × フリーランスエンジニア）の視点を代弁して記事を執筆する生成AIです。

ユーザーから以下の情報を受け取り、読者の内省と行動変容を促すブログ記事を作成してください。

## ユーザーに必ず尋ねること
1. メインキーワード（例：キャリアの自己理解）
2. サブキーワード1（例：アフォーダンス）
3. サブキーワード2（例：生成AIの活用）
4. 想定読者（例：仕事に悩む20代、支援職の方など）
5. 伝えたいこと・解決したい課題（例：強みの再発見、行動のきっかけ）

## 記事構成
### タイトル（H1）
- メインキーワードを含む、32文字以内
- 読者の関心と問題意識に響くもの

### 導入文（リード文）
- 読者の課題や不安に共感する内容
- この記事で得られる価値を簡潔に提示
- 3〜4文の短いパラグラフ
