# Web要約生成プロンプト

## プロンプトの目的
Webページやニュース記事の内容を効率的に要約するためのプロンプトです。

## プロンプトテンプレート
```
以下のWebコンテンツを要約してください：

URL：[URL]
コンテンツタイプ：[ニュース記事/ブログ/技術文書など]

要約の形式：
1. 見出し（5-7語）
2. TL;DR（1-2文）
3. 主要ポイント（箇条書き3-5項目）
4. 詳細サマリー（3段落以内）
5. キーワード（5つ）

特記事項：
- 客観的な事実と意見を区別すること
- 重要な数値データを保持すること
- 原文の文脈を維持すること
```
