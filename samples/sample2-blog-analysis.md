# ブログ記事生成プロンプトの設計意図およびプロンプト構成例

## 設計意図の分析

### ペルソナ定義の明確化
このプロンプトは、特定の専門分野（臨床心理士×キャリア支援者×エンジニア）を持つ人物の視点を代弁するAIを設計しています。AIに「人格」を与えることで、一貫性のある文体と専門的視点を維持しつつ、オリジナリティのある記事を生成できるよう工夫されています。

### 読者中心のコンテンツ設計
ユーザー（記事作成依頼者）から必ず5つの情報を引き出すことで、読者ニーズに合致した記事を生成できるよう構成されています。特に「想定読者」と「伝えたいこと・解決したい課題」を明確にすることで、記事の方向性と具体的価値を担保しています。

### 記事構造の標準化
「導入→本文→内省促進→知識補強→整理→行動喚起」という流れは、読者の思考プロセスに沿いながら、単なる情報提供を超えた「行動変容」への誘導を目指しています。特に、内省セクションや思考の棚卸しセクションは、読者が受動的に情報を消費するだけでなく、能動的に考えるきっかけを提供する工夫です。

### 総合的な出力物の設計
記事本文だけでなく、メタディスクリプションやSNS紹介文、アイキャッチ画像プロンプトまで一括して生成することで、コンテンツマーケティングに必要な要素をワンストップで提供できるよう設計されています。

## プロンプト構成の特徴

### 1. 明確な役割定義
```
あなたは、「異なる専門性を架橋し、実践を通じて人と社会に価値を還元するハイブリッド型支援者」である筆者（臨床心理士 × キャリア支援者 × フリーランスエンジニア）の視点を代弁して記事を執筆する生成AIです。
```
このような明確な役割定義により、AIに特定の立場と視点を与え、一貫性のある記事生成を可能にしています。

### 2. 構造化された情報収集
```
## ユーザーに必ず尋ねること
1. メインキーワード（例：キャリアの自己理解）
2. サブキーワード1（例：アフォーダンス）
3. サブキーワード2（例：生成AIの活用）
4. 想定読者（例：仕事に悩む20代、支援職の方など）
5. 伝えたいこと・解決したい課題（例：強みの再発見、行動のきっかけ）
```
必要情報を明示的に列挙することで、記事作成前の準備を確実にしています。

### 3. 詳細な構成規定
記事の各セクションについて、目的や内容、表現方法まで具体的に指定しています。例えば：
```
### 問いかけ型内省セクション（H2）
- セクション名例：「あなたならどう考えますか？」
- 読者自身の経験に引き寄せる問いかけを通じて、内省と気づきを促す
```
このような具体的な指示により、AIが単なる情報提供ではなく、読者の内省と行動変容を促す記事を作成できるよう誘導しています。

### 4. 制約条件の明示
```
### タイトル（H1）
- メインキーワードを含む、32文字以内
```
```
### 本文（H2 / H3構成）
- PREP法またはSDS法で構成
- メタ認知・水平思考を活用
- サブキーワードは本文・見出しに3回以上登場
```
このような明示的な制約により、SEO対策と読みやすさの両立を図っています。

### 5. 出力形式の明確化
出力すべき内容を順序付きリストで明示し、記事本文だけでなく関連コンテンツも一括生成できるよう設計されています。

## プロンプト構成例（実際の使用イメージ）

以下は、このインストラクションを使用した際のユーザー入力例です：

```
ブログ記事を書いてください。

メインキーワード：キャリアトランジション
サブキーワード1：リフレーミング
サブキーワード2：強み分析
想定読者：30代でキャリアチェンジを考えている会社員
伝えたいこと：不安を抱えながらも自分の可能性を信じて一歩踏み出す勇気
```

このような指示に対して、AIは以下のような構成の記事を生成します：

1. タイトル：「キャリアトランジションを成功させる心理的準備と実践」
2. 導入：読者の不安や悩みに共感し、記事から得られる価値を提示
3. 本文：リフレーミングや強み分析の具体的方法を紹介
4. 内省セクション：「あなたのキャリアをリフレーミングしてみましょう」
5. リサーチセクション：「キャリアトランジションの成功事例から見えてきたこと」
6. 思考の棚卸し：「キャリア移行における不安と可能性のバランスシート」
7. まとめ：今日からできる小さな一歩と、希望を持つための考え方

## まとめ

ブログ記事生成AIプロンプトは、単なる情報提供を超え、読者の内省と行動変容を促す「支援者としての記事」を生成することを目指しています。専門知識と親しみやすさのバランス、情報提供と問いかけのリズム、そして記事としての完成度と実用性を高めるための工夫が随所に見られます。

このプロンプト設計の核心は、「AIに特定の専門家の視点を持たせること」と「読者の思考プロセスに寄り添う記事構成」にあり、単なるコンテンツ生成を超えた価値提供を可能にしています。
