# 技術記事生成プロンプト

## プロンプトの目的
技術的な内容を分かりやすく説明する記事を生成するためのプロンプトです。

## プロンプトテンプレート
```
以下の技術トピックについて解説記事を作成してください：

トピック：[技術トピック]
対象読者レベル：[初級/中級/上級]
技術分野：[プログラミング/インフラ/セキュリティなど]

記事構成：
1. 概要と背景
2. 技術の基本原理
3. 実践的な使用例
   - コードサンプル
   - 設定例
   - ベストプラクティス
4. 注意点とトラブルシューティング
5. 発展的なトピック
6. まとめと参考リソース

追加要件：
- 図表やダイアグラムの説明を含める
- 実行可能なコードサンプルを提供
- 最新のバージョンや互換性に関する情報
```
