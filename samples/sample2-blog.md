# ブログ記事生成プロンプト

## プロンプトの目的
魅力的で読者を引き付けるブログ記事を生成するためのプロンプトです。

## プロンプトテンプレート
```
以下のテーマでブログ記事を作成してください：

テーマ：[テーマ]
ターゲット読者：[読者層]
目的：[記事の目的]

以下の要素を含めて記事を構成してください：
1. 注目を集める導入（フック）
2. 明確な主張や論点
3. 具体例や事例
4. 実践的なアドバイスやヒント
5. 読者の行動を促す結論

文体：[カジュアル/フォーマル]
長さ：[目安の文字数]

SEO対策として以下も含めてください：
- メタディスクリプション
- H2/H3見出し構造
- キーワード案
```
